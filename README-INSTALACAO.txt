SOILUTION — PWA COMPLETO v1.3

PACOTE PRONTO PARA GITHUB PAGES

Arquivos principais:
- index.html: aplicativo completo
- manifest.json: instalação PWA
- sw.js: funcionamento offline/cache
- assets/: logo e ícones do app

PUBLICAR/ATUALIZAR NO GITHUB
1. Abra o repositório do Soilution.
2. Substitua os arquivos antigos pelos arquivos DE DENTRO desta pasta/ZIP.
3. Confirme que index.html, manifest.json, sw.js e a pasta assets ficam na raiz do repositório.
4. Faça Commit changes.
5. Aguarde o GitHub Pages atualizar.

IMPORTANTE SOBRE O ÍCONE
- Esta versão usa nomes novos (v3) e um cache novo para evitar que o celular continue mostrando o logo antigo.
- Se o Soilution já estiver instalado na tela inicial, remova o atalho/app antigo e instale novamente após o GitHub Pages atualizar.

DADOS
- Os dados são gravados no LocalStorage do navegador/aparelho.
- Atualizar os arquivos do GitHub normalmente NÃO apaga os dados do app.
- Mesmo assim, use Dados > Exportar backup antes de alterações importantes.

FUNÇÕES INCLUÍDAS
- Fazendas
- Talhões: cultura, idade, data de plantio e observações
- Baterias com localização GPS
- Vários extratores por bateria com profundidades diferentes
- Leituras de CE e/ou pH
- Data/hora automática e editável
- Observações por leitura
- Edição e exclusão de leituras
- Histórico e filtros
- Relatórios de 7 dias, 30 dias, mês atual e todo o período
- PDF compartilhável
- Exportação para Excel
- Backup/importação JSON
- PWA instalável e funcionamento offline após primeiro carregamento
